# Design Tokens

`src/app/globals.css`의 `:root` 값을 보여준다. 값은 DESIGN.md §6의 근사치이고, Claude Design 시안 원본 값을 받으면 교체한다 (D-4).

글자 크기, 간격, radius 스케일은 디자인에서 확인되지 않아 Tailwind 기본값을 쓴다.
