# SHI-188 불러오는 중 화면을 스켈레톤으로 (D-5 Loading)

## 개요
데이터를 불러오는 동안 텍스트 "불러오는 중..."만 보이던 화면을, 실제 화면 배치를 흉내 낸 스켈레톤으로 바꾼다. 시안에 Loading 디자인이 없어(D-5) 새 디자인을 만들지 않고 **기존 화면의 배치와 토큰만** 쓴다. 분석·범위·AC·테스트 기준은 `docs/SKELETON_SPEC.md`에 있다.

## 열린 질문
- **Q4 (사용자 검토 중) 모든 로딩을 스켈레톤으로 통일할지.** 조사 결과 일괄 교체는 권하지 않는다. 대신 **규칙으로 통일**한다:
  - 화면·목록·구역이 서버 데이터를 기다리고 배치를 아는 경우 → 스켈레톤 (S1~S8)
  - 처리·이동 중(로그인 콜백 "로그인 처리 중...", 404 이동 직전, ONB 판별 후 이동), 버튼 안 상태(`더 보기`, 참여·취소 진행 중) → 스켈레톤을 쓰지 않는다(구조가 없고 1초 안팎)
  - 개설 하이드레이션(`CreateScheduleFlow`, 서버 데이터 없음, 아주 짧음) → 텍스트 유지 또는 CRT-01 폼 모양 스켈레톤. 선택 필요
  - 홈 `Suspense` fallback(지금 비어 있음) → 빈 화면은 NN/g도 피하라는 상태. 홈 배치를 확인한 뒤 목록 스켈레톤 fallback 추가를 제안
- Q5 탭 전환·필터 적용 때 이전 목록을 유지할지, 스켈레톤으로 바꿀지(현재 동작 문서화만)
- Q6 상세 `GUEST` 재발급 재조회 중 스켈레톤을 다시 보일지
- Q7 ✅ 해결(2026-11-15, 사용자): 표시 지연 200ms, 최소 표시 시간 없음. 스켈레톤 개수는 현 구현 유지.
- Q2 새 Loading 시안이 있는지(Figma 미확인)
