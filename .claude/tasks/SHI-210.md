# SHI-210 홈 메인 배너 아이폰 사파리 표시 수정과 E2E WebKit 추가 (LIST-06-1)

## 개요
SHI-200(홈)의 하위 이슈. 홈 메인 배너가 아이폰 사파리에서 화면 오른쪽으로 넘쳐 오른쪽 모서리와 여백이 잘려 보인다. 크롬(PC 반응형 모드)에서는 정상이다.

## 기준 문서
- `docs/USER_FLOW.md` §5.1(홈), 사용자 스크린샷 `홈 화면 배너 크기 오류.PNG`(2026-11-23, 아이폰 사파리 375pt)

## 결정 사항
- 2026-11-23 원인(Playwright WebKit에서 재현 확인): 배너가 `aspect-2/1`과 `min-h-48`(192pt)을 같이 써서, 사파리가 최소 높이를 비율로 폭에 넘겨 폭이 약 384pt(가용 335pt)가 된다. 크롬은 같은 코드에서 넘치지 않는다.
- 2026-11-23 `aspect-2/1`을 빼고 `min-h-48`만 둔다. 폰 크기에서는 크롬에서 보던 모습과 같고, 폭이 400pt 넘는 화면에서만 높이가 204pt에서 192pt로 낮아진다.

- 2026-11-23 (사용자 스크린샷 `홈화면 배너 클릭 시 오류 확인.png`) 배너를 꾹 누르면 사진은 제자리에 있고 배경 초록(`bg-brand`)만 사진보다 사방 20~30px 크게 나와 초록 테두리처럼 보인다. 음수 z-index 레이어(사진 `-z-20`, 막 `-z-10`)와 `isolate` 구조 때문으로 추정한다(사파리의 눌림 효과는 PC에서 재현할 수 없어 확인하지 못했다). 레이어를 음수 z-index 없이 쌓도록 바꿨지만 초록색이 남았다(사용자 확인). 미리보기는 보이는 게 좋고 초록색은 미리보기가 뜨기 전에만 보여서(사용자), 링크 요소의 배경색(`bg-brand`)을 쓰지 않기로 했다(사용자 결정 2026-11-23). 사진을 못 불러올 때는 어두운 막 위에 글자만 보인다. `-webkit-touch-callout: none`(미리보기 끄기)은 쓰지 않는다.

## 단계
- [x] 3. 배너 링크에서 배경색을 빼고, 레이어를 음수 z-index·`isolate` 없이 쌓는다(사진 → 막 → 글자). 평소 모양은 Chrome·WebKit 모두 수정 전후 같고 둥근 모서리 가장자리 픽셀만 다르다(초록 비침 제거) — 확인: 아이폰 사파리에서 배너를 꾹 눌러도 미리보기 전에 초록색이 보이지 않는다(사용자가 실기기에서 확인함, 2026-11-23).
- [x] 2. E2E WebKit 추가(2026-11-23 사용자 요청으로 SHI-210에 합침): `playwright.config.ts`에 `chrome`·`webkit` 두 프로젝트, 클립보드 테스트 2개는 `captureClipboard`로 바꿔 두 엔진에서 확인, 뒤로가기 캐시 4개는 WebKit에서 건너뜀, 배너 폭 재발 방지 테스트 추가 — 확인: `pnpm test:e2e`가 두 엔진 모두 통과하고, `aspect-2/1`을 되돌리면 WebKit 배너 테스트만 실패한다(`Received: -14`).
- [x] 1. `MainBanner.tsx`에서 `aspect-2/1` 제거, 이유 주석 — 확인: 아이폰 사파리에서 홈을 열면 배너 오른쪽에 둥근 모서리와 20pt 여백이 보인다.

- Linear SHI-210(SHI-200 하위). 구현·자동 검사 완료. Playwright WebKit으로 수정 전후 확인 완료. 아이폰 실기기 확인은 배포 뒤.

## 공통 코드 변경 영향 범위
- 홈 `MainBanner`만 바뀐다. E2E 설정이 바뀌어 `pnpm test:e2e`가 두 엔진으로 돌아 약 2배 걸린다(전체 약 1.8분). 처음 한 번 `playwright install webkit`이 필요하다. CI는 E2E를 돌리지 않으므로 영향 없다.
- 기준 이미지(`scheduleCreate.spec.ts-snapshots`)는 프로젝트 이름이 붙는다. 기존 파일을 `-chrome-darwin`으로 옮겼고 `-webkit-darwin`을 새로 만들었다. 처음 실행에서 개설 팝업 테스트가 실패한 건 이 기준 이미지가 없어서였다(불안정이 아니다).

## 리뷰
- 2026-11-23 변경이 클래스 한 개 제거와 주석뿐이라 에이전트 리뷰 없이 diff를 직접 점검했다. 크롬 엔진에서는 수정 전후 배너 크기가 같음(335×192, 375px 폭)을 확인했다. 이후 Playwright WebKit(v2370)을 설치해 확인했다: 수정 전 375px 폭에서 배너 폭 384px(오른쪽으로 29px 넘침), 수정 후 335px. 아이폰 실기기는 배포 뒤 확인한다.
