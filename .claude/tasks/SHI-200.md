- 홈은 `/`, 일정 목록은 `/schedules`. 일정 목록의 탭 구성(3탭)은 이 이슈에서 바꾸지 않는다(일정 탭 개편은 따로).
- 홈 화면 추가 안내(ONB)의 7일 뒤 표시는 홈(`/`)에서 한다. 개설 완료 팝업은 목록 화면(`/schedules?tab=created`)에 그대로 둔다.
- 다가오는 일정: `GET /schedules/next` 1건(2026-11-23 서버 API로 바꿈. 이전에는 `/participating`·`/hosted`를 합쳤다).
- 곧 마감돼요: `GET /schedules?sort=CLOSING_SOON&size=10`(2026-11-23 서버 정렬로 바꿈). 카드는 공통 `ScheduleCard`에 `N자리 남음` 배지, 시간은 기존 `MM월DD일(요일) HH:MM`.
- 활동 버튼은 활동 목록의 `code`(`ESCAPE_ROOM`·`BOARD_GAME`·`WALK`)로 3개를 고르고 이름은 서버 활동 이름 그대로(`방탈출`·`보드게임`·`산책`) 보인다(F-27, 시안 `홈 화면 수정2`도 `산책`). 누르면 `/schedules?activity=<활동 ID>`.
- `모집 중인 일정 전체보기` 버튼은 `곧 마감돼요`가 0개로 숨겨져도 남긴다(`추정`).
- 메인 배너 이미지는 `메인배너.png`(1672×941, 2MB)를 JPEG 1200px(약 140KB)로 줄여 `public/images/home-banner.jpg`에 둔다. 글자가 읽히도록 어두운 막을 한 겹 깐다(`추정`).
- 슬라이드는 CSS `scroll-snap`으로 만든다(새 라이브러리 없음). 스크롤 막대 숨김용 `scrollbar-hidden` 유틸을 `globals.css`에 추가했다.
- 일정 목록 밖에서 목록으로 가는 이동(상세 뒤로가기 대체 경로, 없는 일정 안내 뒤 이동, 개설 1단계 뒤로가기)은 이전과 같게 `/schedules`로 보낸다. 로그아웃·로그인 없이 둘러보기는 홈(`/`)이다. 상세 직접 진입 뒤 `뒤로`가 홈이어야 하는지는 팀 확인이 필요하다.
