# SHI-214 홈 메인 배너 클릭 시 오류 수정 (LIST-06-1)

## 개요
SHI-200(홈)의 하위 이슈. 홈 메인 배너를 아이폰 사파리에서 꾹 누르면 미리보기가 뜨기 전에 초록색이 보인다. 링크 요소의 초록 배경색(`bg-brand`)이 사진보다 크게 보이는 것으로 추정한다. SHI-210(폭 넘침 수정, E2E WebKit)이 머지된 뒤에 나온 후속 수정이다.

## 기준 문서
- `docs/USER_FLOW.md` §5.1(홈), 사용자 스크린샷 `홈화면 배너 클릭 시 오류 확인.png`(2026-11-23)

## 결정 사항
- 2026-11-23 (사용자) 배너 전체와 `서비스 소개 보기 ↗` 버튼은 계속 클릭되어야 한다. 꾹 눌렀을 때의 미리보기도 보이는 편이 좋다(`-webkit-touch-callout: none`은 쓰지 않는다).
- 2026-11-23 (사용자) 초록색은 미리보기가 뜨기 전에만 보이므로 배경색을 쓰지 않는다. 링크 요소의 `bg-brand`를 없앤다. 사진을 못 불러오면 어두운 막 위에 글자만 보인다.
- 2026-11-23 레이어 구조만 바꾼 1차 시도(음수 z-index와 `isolate` 제거)로는 초록색이 남았다. 배경색을 없앤 뒤 사용자가 아이폰 실기기에서 초록색이 보이지 않음을 확인했다. 사진·어두운 막·글자는 음수 z-index 없이 문서 순서대로 쌓는다.
