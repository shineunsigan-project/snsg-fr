## PM 문구 (원문 그대로)
| 항목 | 문구 | 쓰는 곳 |
|---|---|---|
| 한 줄 소개 | 보드게임·방탈출 모임, 기다리지 말고 하고 싶을 때 직접 열어요 | 페이지 제목(title), 홈 보이지 않는 대표 제목(h1) |
| 서비스 소개 설명 | 쉬는시간은 보드게임·방탈출 모임을 직접 열고 사람을 모아 동행하는 서비스예요. 망설이지 말고, 홍대·신촌·성수에서 가보고 싶었던 장소로 모임을 열어 보세요. | 홈 공유 미리보기 설명(og:description) |
| 검색 결과 설명 | 원하는 보드게임·방탈출 모임이 안 보인다면 기다리지 말고 직접 열어 보세요. 가보고 싶었던 장소를 고르면 바로 모임을 열고, 사람을 모아 동행해요. | 검색 결과 설명(description) |
| 일정 공유 제목 | `[{활동}] {활동명} · {MM월DD일(요일) HH:MM}` 예: [보드게임] 보드게임 추리 한 판 · 11월22일(토) 19:30 | 일정 상세 og:title |
| 일정 공유 설명 | `{구} {장소명} · {전체 인원}명 모집 \| 쉬는시간에서 모임을 보고 바로 참여해 보세요.` | 일정 상세 og:description |
- 날짜 형식: 월·일 두 자리. 해요체, 글자 수는 공백 포함. 쓰지 않을 표현: 검증된 매장·운영자가 확인한 매장, 무료(구독제), 정기 모임, 소개팅·데이팅·썸·소셜링
- 활동별 소개(PM 5번)는 쓸 화면이 없어 이번 범위에서 쓰지 않는다

## 코드 확인 결과 (2026-11-24)
- 홈 `/`(HomeScreen)와 일정 목록 `/schedules`는 별개 화면이다. 홈은 인사·다가오는 일정·활동 타일·곧 마감·새 일정과 `모집 중인 일정 전체보기` 링크, 목록은 탭·필터
- 홈·목록·상세 화면 컴포넌트는 모두 `"use client"`라 데이터는 화면이 뜬 뒤에 받는다. 상세 `page.tsx`만 서버 컴포넌트이므로 거기서 `generateMetadata`로 서버 조회가 가능하다
- 일정 상세 응답에 공유 문구에 필요한 값이 모두 있다: `category.name`(활동), `title`(활동명), `startAt`, `place.regionName`(구), `place.name`(장소명), `capacity`(전체 인원), `displayStatus`
- 상세 응답의 `category`는 `{id, name}`만 있고 `code`(예: BOARD_GAME)는 없다. 활동 목록 API에는 `code`가 있다
- 현재 `layout.tsx` metadata는 title `쉬는시간`·appleWebApp·apple 아이콘뿐이다. 설명·공유 정보·canonical·robots·sitemap·구조화 데이터가 없다. `manifest.ts`와 아이콘 3종(apple-touch·192·512)은 있다. 파비콘 파일은 `src/app`·`public`에서 찾지 못했다
- 일정 공유 주소는 `window.location.origin/schedules/{id}`라 접속한 주소가 그대로 공유된다
- `proxy.ts`는 `/login` 하나만 처리한다. noindex는 각 페이지 metadata로 둔다
- Next.js 16.3.8: metadata API(`generateMetadata`·`robots.ts`·`sitemap.ts`) 사용 가능
- `docs/HANDOFF.md`의 배포 주소 `app.shineunsigan.com`은 오래된 값이다. 갱신한다
