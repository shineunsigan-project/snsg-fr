# 옵시디언 노트 정리

아티팩트를 발행하면 같은 내용을 옵시디언에도 남긴다. 아티팩트는 링크로 공유·확인하는 용도, 옵시디언은 팀이 보관·검색하는 기록이다.

## 위치와 이름
- 노트: `snsg-fr-secondbrain/01_Projects/쉬는시간/<제목> <YYYY-MM-DD>.md`
- 이미지: `snsg-fr-secondbrain/01_Projects/쉬는시간/attachments/<노트 파일 이름과 같은 폴더>/`
  - 파일 이름은 영문 소문자·숫자·`-`, 화면 접두어를 붙인다(예: `list-01-home.jpg`, `crt06-Before.jpg`).
  - jpg(quality 85), 폭 390px 정도로 줄인다(캡처가 2배면 절반).
- `00_Inbox/`는 기획서·시안 원본 자리라 노트를 두지 않는다.
- 옵시디언 폴더는 git에 올리지 않는다(`.claude/rules/git-workflow.md`).

## 형식 (기존 노트와 같게)
```
---
title: <제목>
date: <YYYY-MM-DD>
tags: [쉬는시간, <기능>, <종류: 화면흐름·디자인·점검 등>]
screen: <화면 ID>
linear: SHI-<번호>
artifact: <아티팩트 URL>
---

# <제목> (<화면 ID>)
<한두 문장 요약>

- 원본: [<아티팩트 제목>](<URL>)
- 기준: 브랜치·커밋, 캡처 조건(화면 크기, 실제 기기 여부, 가짜 응답 여부)
- 관련: [[다른 노트 이름]]
- 이미지: `attachments/<폴더>/`

## 섹션들 (아티팩트의 섹션 순서 그대로)
설명 몇 줄 + 이미지. 여러 장은 표로 나란히: | 이름 | ... | / | ![[파일.jpg\|200]] | (표 안에서는 `|`를 `\|`로)

## 남은 것
미정 항목 ID(F-x, D-x), 임시 계약, 다음 작업
```
- 아티팩트 내용을 요약해 옮기고, HTML·스타일은 옮기지 않는다. 문구·결정·근거는 빠뜨리지 않는다.
- 같은 아티팩트를 다시 발행했으면 같은 노트를 고친다(날짜는 처음 만든 날 그대로, 본문에 갱신 날짜 한 줄).
- 관련 노트가 있으면 `관련:`에 서로 링크한다(새 노트의 링크를 기존 노트에도 추가).

## 마무리
- 사용자에게 노트 경로를 알린다.
