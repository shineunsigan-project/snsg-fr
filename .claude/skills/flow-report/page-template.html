  • 목록 데이터는 가짜 응답(MSW)입니다. 실제 백엔드 목록 API는 아직 없습니다.
  • 브라우저 크기를 390×844로 맞춘 캡처이고, 실제 기기에서 본 화면이 아닙니다.
  • 남은 미정: 결과 없음 문구(F-19), N자리 남음 배지(D-9 보류).
  • 카드를 누르면 일정 상세로 갑니다. 상세 화면은 SHI-155에서 작업 중이라 따로 정리합니다.
