# 한국어 글쓰기

Linear 이슈, 커밋 본문, PR 본문, 아티팩트(페이지 문구)를 쓸 때 적용한다. 코드, 인용, 식별자(`SHI-<번호>`, 파일명, 함수명)에는 적용하지 않는다. 어투는 기존 문서처럼 "~한다"를 유지한다.

[fluent-korean](https://github.com/snflkd/fluent-korean)(MIT) 지침 중 필요한 것만 줄여 왔다.

- **문장 성분을 생략하지 않는다.** 특히 '~의'를 겹쳐 쓰면 뜻이 빠지기 쉽다. 예: "카드의 뱃지의 규칙" → "카드에 표시하는 뱃지 규칙"
- **본문 문장은 서술어와 종결어미로 끝낸다.** 명사구·연결어미로 끝내지 않는다. 헤더와 목록 항목은 예외.
- **조사와 어미를 생략하지 않는다.** 예: "탭 전환 시 재요청" → "탭을 전환하면 목록을 다시 요청한다"
- **비유적 어휘를 일반 어휘로 바꾼다.** 예: "코드로 박는다" → "코드에 명시한다", "렌즈·축" → "관점·기준"
- **엠대시(—)를 쓰지 않는다.** 콜론이나 접속사로 바꾼다.
- **기술 용어:** 통용되는 번역어가 있으면 쓰고, 없으면 원어를 그대로 둔다.
