# 폼과 유효성 검사

- **쓰는 곳:** React Hook Form + Zod는 프로필 완성, 프로필 수정, 일정 개설에만.
- **쓰지 않는 곳:** 입력이 하나뿐인 폼(취소 사유, 제보 유형, 댓글, 필터 시트)은 컴포넌트 state.
- **스키마 위치:** `features/<기능>/schemas/`. 프로필 완성·수정은 같은 스키마. 같은 검증 로직을 두 곳에 쓰지 않는다.
- **규칙과 문구:** USER_FLOW §4.1 "입력값 유효성 검사"·"유효성 검사 문구"를 그대로 옮긴다. 문서에 없는 규칙은 추가하지 않는다. 서버 규칙(snsg-be api-guide "가입 요청의 입력 규칙")과 다르면 보고한다.
- 수치 기준(이름·닉네임 길이, 최소 나이, 이미지 용량)은 스키마 파일 한 곳에 상수로. 미정 값은 `TODO(F-14)`.
- **표시:** 문구는 필드 바로 아래. 칸을 벗어날 때(blur) 그 칸만, 제출할 때 전체를 검사한다. 입력 중에는 검사하지 않는다. 값을 고치면 그 오류를 지운다.
- **서버 검사:** 닉네임 중복처럼 서버 응답이 필요한 검사는 비동기로. 서버의 `400 INVALID_REQUEST` `errors[]`는 해당 칸 아래에 서버 문구로 보여준다.
